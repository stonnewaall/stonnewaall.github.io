# Robert J. McGuire — Personal Homepage

Static HTML/CSS/JS site designed for GitHub Pages.

## Deploy
1. Copy the contents of this folder into the root of the `stonnewaall.github.io` repository.
2. Replace the placeholder LinkedIn and email URLs in `index.html`.
3. Commit and push.
4. In GitHub: Settings → Pages → deploy from the main branch/root if Pages is not already configured.

## Personalization
The content is intentionally easy to edit directly in `index.html`.
The theme toggle is stored in localStorage.
The hero image is `assets/hero.png`.
